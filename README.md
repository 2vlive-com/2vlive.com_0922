# เอ็มบัปเป้ไม่วิจารณ์ผู้ตัดสิน หลังเรอัล มาดริดแพ้แอตเลติโก มาดริด 1-2
คีลิยัน เอ็มบัปเป้ไม่ขอวิจารณ์ผู้ตัดสิน หลังเรอัล มาดริดแพ้แอตเลติโก มาดริด 1-2 ในเกมดาร์บี้ แม้ยอมรับว่ามีความผิดพลาดเกิดขึ้นระหว่างเกม ผลการแข่งขันทำให้เรอัล มาดริดตามหลังบาร์เซโลนา 6 คะแนน หลังลงเล่นไป 7 นัด
เอ็มบัปเป้ยอมรับผู้ตัดสินมีความผิดพลาด
เอ็มบัปเป้กล่าวว่าเขาไม่ใช่นักเตะที่พูดถึงผู้ตัดสินบ่อย และจะไม่เริ่มทำเช่นนั้นในเวลานี้ แม้มีความคิดเห็นส่วนตัวต่อการทำหน้าที่ของ Miguel Ángel Ortiz Arias เขาย้ำว่าผู้ตัดสินก็เป็นมนุษย์และสามารถทำผิดพลาดได้ แต่ไม่ต้องการขยายความถึงประเด็นดังกล่าว
มูรินโญ่มองว่าควรมีใบแดงสองครั้ง
โชเซ่ มูรินโญ่ระบุหลังเกมว่า Ortiz Arias ไม่ได้แจกใบแดงจากจังหวะปะทะรุนแรงในครึ่งแรกสองครั้ง พร้อมนำภาพเหตุการณ์ไปประกอบการแถลงข่าว โดยเหตุการณ์หนึ่งเกี่ยวข้องกับคริสเตียน โรเมโร และอีกเหตุการณ์เกี่ยวข้องกับคังอิน ลี
โรเมโรได้รับใบเหลืองจากจังหวะเหยียบเข่าของจู๊ด เบลลิงแฮม หลังมีการตรวจสอบจาก VAR ส่วนเบลลิงแฮมเคยถูกลงโทษจากจังหวะปะทะดังกล่าว ขณะที่ลีไม่ถูกลงโทษจากจังหวะยกเท้าสูงโดนข้อเท้าของเฟเดริโก บัลเบร์เด
แอตเลติโก มาดริดคว้าชัย 2-1
แอตเลติโก มาดริดขึ้นนำในครึ่งหลังที่สนาม Metropolitano จากจุดโทษของอเลฮานโดร กรีมัลโด หลังดีน ฮุยเซนถูกไล่ออกจากสนาม จากนั้นโจนาธาน เดวิดทำให้ทีมขึ้นนำ 2-0 ก่อนอันโตนิโอ รือดิเกอร์ยิงประตูตีตื้นให้เรอัล มาดริดในช่วงท้ายเกม
นี่เป็นความพ่ายแพ้นัดที่สองของเรอัล มาดริดในฤดูกาลนี้ หลังแพ้เรอัล เบติส 0-1 ก่อนหน้านี้ในเดือนเดียวกัน
เอ็มบัปเป้มองว่าความพ่ายแพ้ในเกมดาร์บี้เป็นการถอยหลังของทีม แม้นักเตะจะทุ่มเทเต็มที่ เขาย้ำว่าทีมต้องทำงานหนักขึ้นและยังมีเส้นทางอีกยาวไกลในฤดูกาลนี้
